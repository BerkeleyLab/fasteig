## Reporting bugs

Users with access to the FASTEIG GitHub repository may report reproducible
bugs through [GitHub Issues](https://github.com/BerkeleyLab/fasteig/issues).
If the repository or issue tracker is not accessible, contact the primary
support contact above.

When reporting a problem, please include as much of the following information
as possible:

- FASTEIG version or Git commit
- Operating system and machine
- Compiler and compiler version
- CPU or CUDA build configuration
- Input file and a minimal reproducer
- Complete error output
